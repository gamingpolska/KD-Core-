## O projekcie

**KD Core** to darmowy program do diagnostyki komputerów i monitorowania podzespołów, tworzony przez YungKaczka.

Projekt ma na celu zapewnienie wygodnego dostępu do narzędzi diagnostycznych i informacji o stanie komputera w jednym miejscu.

Program jest tworzony w języku C++ z naciskiem na wydajność, prostotę obsługi i nowoczesny interfejs.

## Funkcje

- Monitorowanie procesora (CPU).
- Monitorowanie pamięci RAM.
- Informacje o karcie graficznej (GPU).
- Monitorowanie dysków.
- Diagnostyka systemu.
- Moduły diagnostyczne.
- Raporty systemowe.
- Nowoczesny interfejs graficzny.
- Niskie zużycie zasobów.

*Lista funkcji będzie rozwijana wraz z kolejnymi aktualizacjami.*

## System operacyjny

- Windows 10
- Windows 11

KD Core jest projektem przeznaczonym dla systemu Windows. Nie planuje się oficjalnej wersji Linux.
