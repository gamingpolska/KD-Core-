## O projekcie

**KD Core** to aplikacja do diagnostyki komputerów i zarządzania narzędziami systemowymi, tworzona przez **YungKaczka**.

Celem projektu jest stworzenie lekkiego, nowoczesnego i wygodnego programu, który pozwoli monitorować podzespoły komputera, diagnozować problemy systemowe oraz korzystać z narzędzi serwisowych.

Projekt wykorzystuje własną identyfikację wizualną Graphite + Light Blue.

## Funkcje

- Monitorowanie podzespołów komputera.
- Statystyki procesora (CPU).
- Monitorowanie pamięci RAM.
- Informacje o karcie graficznej (GPU).
- Monitorowanie dysków.
- Diagnostyka systemu.
- Moduły diagnostyczne.
- Raporty systemowe.
- Nowoczesny interfejs graficzny.
- Niskie zużycie zasobów.

*Funkcje są rozwijane i rozbudowywane.*
